# research/materials

Source notes backing `docs/PRIOR_ART.md`. One file per theme. Every note records the
URL, the retrieval date and the retrieval outcome, and separates verbatim quotation from
paraphrase.

Retrieval vocabulary used in these notes:

| Tag | Meaning |
|---|---|
| `FETCHED_OK` | The page or document was retrieved and read on the stated date |
| `FETCHED_PDF` | A PDF was retrieved and its pages were read directly |
| `FETCH_403` | The server refused with HTTP 403 on the stated date |
| `FETCH_TLS_FAIL` | The TLS certificate could not be verified on the stated date |
| `SEARCH_INDEX_ONLY` | Only a search-engine summary was obtained; wording is not verbatim |

A `SEARCH_INDEX_ONLY` claim is never quoted as if it were verbatim, and any number
carried by one is labelled unverified where it is used.

All notes retrieved on **2026-09-08**. No supplier or author was contacted.
